给 **BBS mod** 加一条新的轨道：**人声轨道**。输入一句台词，mod 用微软 Edge 在线语音把它合成出来，
像剪辑软件的 AI 配音一样贴在时间轴上。

## 这个版本面向

| 组件 | 要求 |
| --- | --- |
| Minecraft | **26.3** |
| Fabric Loader | ≥ 0.19.5 |
| Fabric API | 0.162.0+26.3（≥ 0.162.0 的其他 26.3 版本应该也行） |
| BBS mod | **2.3.2（26.3）** |
| Java | **25**（26.3 本身要求 Java 25） |

26.3 起 Mojang 直接发未混淆的 jar、Fabric 也没有 yarn 映射了，所以这个版本是对着 BBS 2.3.2-26.3
单独编译的（Loom 1.18.4 / Gradle 9.7.1 / Java 25）。**1.20.4 请下载另一个版本**。

## 安装

把 `bbsvoice-1.0-26.3.jar` 丢进 `mods/`。mp3 解码器（JLayer）已经内嵌，不需要别的文件。

## 本版新增：音色从 14 个扩到 27 个，选择改成可搜索列表

* **多语音色 12 个**（英/德/法/意/韩/葡的 `*MultilingualNeural`）：也能读中文，只是带各自的口音。
  实测同一句中文，它们念出来 **3.62–4.15 秒**，和中文基线晓晓的 **3.70 秒**同一量级 —— 说明是按中文朗读，
  不是逐字母拼读。想要「带口音的中文旁白」就用它们。
* **角色配音：曼波**（音色 id `ext:manbo`）。它不是微软的声音，走**第三方免费接口**，属于**可选的实验性音色**：
  免费公共接口会限流、会变慢，也可能哪天就没了。**失败只影响这一条音色**，Edge 的 26 个照常用，
  缓存过的台词照常播放。mod 会按顺序试备用镜像，并适配它返回的 **48 kHz** 音频（游戏要 24 kHz）。
* 人物按钮从「◀ ▶ 循环 14 条」换成**可搜索列表**：点开输几个字就能筛，27 条不用一条条翻。
  列表顺序即分类（普通话 → 方言 → 粤语 → 台湾 → 多语音色 → 角色音），每条标签都写明它是什么。
* 设置里的**默认配音人物**也认角色音：直接填 `ext:manbo` 即可。

## 本版修复：合成端点 2026-10 搬家（合成一度全挂）

2026 年 10 月起，微软把 Edge 朗读的**合成**端点迁到 `api.msedgeservices.com`，旧端点对合成 websocket
直接返回 **403**（先是大多数国家，10 月 12 日起美国也一样）。这不是本 mod 的问题，也不是 Java 版本问题
——同一台机器上语音列表端点仍返回 200，换 Java 17/21 跑也一样 403。现已指向新端点，
客户端令牌与 `Sec-MS-GEC` 系列参数都没变。

顺带：合成失败时的报错现在会带上 **HTTP 状态码**（例如 `HTTP 403 - the Edge speech service refused
the websocket upgrade`），不再只吐一个 `WebSocketHandshakeException` 类名。

## 本版修复：429 限流现在会自动退避重试

新端点按 IP 限流。一部片子里新台词一多，串行渲染会连着开 socket，尾部请求就拿到 **429**，
表现就是「合成不出来东西」（日志里 `Could not synthesise ... HTTP 429`）。

现在：429 / 5xx 最多自动重试 **4 次**，退避 1.2s → 2.4s → 4.8s（上限 20s），服务端给了 `Retry-After`
就按它等；两次握手之间还有 **700ms 最小间隔**，从源头少撞限流。403 / 400 这类确定性拒绝不重试，
直接报错——重试只是让你多等。重试时日志会写明状态码和等待时间，便于排障。

## 功能

* **27 个配音音色**：普通话 6（晓晓/晓伊/云希/云健/云扬/云夏）、方言 2（东北话/陕西话）、粤语 3、台湾国语 3、
  **多语音色 12**、**角色配音 1（曼波，第三方服务，见上）**
* **音量 / 语速 / 音高**三条独立曲线，都支持**关键帧**；另有 **6 个情绪预设**（一键插关键帧，之后还能拖）
* **自动适配轨道长度**：台词比轨道长时整条加速，避免被截断
* **剪辑会自动长成语音的长度**（只增不减）；你手动拖过的剪辑不动
* 支持**自己录音配音**、起始偏移
* 两种轨道层级：**影片级旁白** / **演员级 3D 人声**
* 合成结果缓存成 wav，**同一句话只联网一次**，之后离线可用

> ⚠️ 合成需要联网。免费，不需要账号、不需要 API key、不需要装 Python。
