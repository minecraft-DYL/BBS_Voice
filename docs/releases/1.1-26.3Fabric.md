**BBS mod** 的人声轨道：一句台词合成成配音，像剪辑软件的 AI 配音一样贴上时间轴。1.1 是**错误提示**的改进版，
功能与 1.0 相同（27 个音色、可搜索列表、曼波角色音），完整功能说明见 `1.0-26.3Fabric` 那一版。

## 这个版本面向

| 组件 | 要求 |
| --- | --- |
| Minecraft | **26.3** |
| Fabric Loader | ≥ 0.19.5 |
| Fabric API | 0.162.0+26.3（≥ 0.162.0 的其他 26.3 版本应该也行） |
| BBS mod | **2.3.2（26.3）** |
| Java | **25**（26.3 本身要求 Java 25） |

26.3 起 Mojang 直接发未混淆的 jar、Fabric 也没有 yarn 映射了，所以这个版本是对着 BBS 2.3.2-26.3
单独编译的（Loom 1.18.4 / Gradle 9.7.1 / Java 25）。**1.20.4 请下载另一个版本**。

## 安装

把 `bbsvoice-1.1-26.3.jar` 丢进 `mods/`。mp3 解码器（JLayer）已经内嵌，不需要别的文件。

## 本版新增：合成失败时告诉你是哪一种，并给出该怎么办

以前失败只是把后端的原始报错截断贴在状态栏上——分不清是「被限流」「被风控拒绝」还是「自己断网」，
也拿不到下一步该做什么。现在状态栏直接给建议，鼠标悬停看引擎抛出的原始报错：

| 状态栏会写 | 什么情况 | 建议 |
| --- | --- | --- |
| 被服务限流（HTTP 429） | 微软端点按 IP 限流 | 等十几秒再合成，或一次少合成几句 |
| 服务风控拒绝了这次合成（HTTP 401/403） | 令牌/头部被反滥用检查拒绝 | 等几分钟再试；一直如此说明服务又改了协议 |
| 服务端故障（HTTP 5xx） | 对面出问题，不是本 mod | 稍后再试 |
| 合成超时 | 网络慢，或正在被限流 | 稍后重试 |
| 连不上服务 | DNS 解析失败 / 连接被拒 | 检查网络、代理、防火墙 |
| 这个音色念不出这段文本 | 常见于用非中文音色念中文 | 换个音色，或改掉生僻符号 |
| 服务返回了空音频 | 返回静音或空流 | 再点一次「重新合成」 |
| 第三方角色音色接口失败 | 曼波那条走的是免费公共接口 | 换回 Edge 音色即可，不影响别的轨道 |
| 音频在本地解码失败 | 服务给的数据不完整 | 重新合成一次 |

分类逻辑是纯 Java 的 `FailureHint`，**单元测试钉住了两个后端真实抛出的报文**——以后改了报错措辞会挂测试，
而不是悄悄退化成「未知原因」。原始报错仍然保留在悬停提示和游戏日志里，排障不用翻半天。

## 功能（与 1.0 相同的部分）

* **27 个配音音色**：普通话 6、方言 2（东北话/陕西话）、粤语 3、台湾国语 3、**多语音色 12**、**角色配音 1（曼波，第三方服务）**
* 人物选择是**可搜索列表**（27 条不用一条条翻）；**音量 / 语速 / 音高**三条曲线支持**关键帧**；**6 个情绪预设**
* **自动适配轨道长度**；剪辑会自动长成语音的长度；支持**自己录音配音**；影片级旁白 / 演员级 3D 人声
* 合成结果缓存成 wav，**同一句话只联网一次**，之后离线可用

> ⚠️ 合成需要联网。免费，不需要账号、不需要 API key、不需要装 Python。
